# Greeting (Vaani: Persona > Identity > Greeting message)

Paste exactly this line. It says it is an AI and that the call may be recorded, in the first breath, and greets in both languages:

```
Hello, नमस्ते! You've reached Aangan Studio. I'm an AI assistant, and this call may be recorded. How can I help you today?
```

Leave "Let user speak first" OFF, so the greeting always plays.
